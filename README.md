# UCL PHAS0020 projects 
Klara Kurucova | UCL

This repo organises my projects that I worked on as part of my 2nd year module at UCL PHAS0020: Practical Astrophysics and Computing. There are five weekly tasks as well as my final project which focused on modelling spectral lines for the star Alcyone. All of the tasks have been created by Prof. G. Savini and data collected at the UCLO. The tasks have been completed indvidually as part of my assessment for this module.
